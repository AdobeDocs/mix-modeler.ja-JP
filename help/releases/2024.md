# 2024 Mix Modeler リリースノート

## 2024年10月

| 機能 | 説明 | 一般公開（GA） |
|---|---|---|
| **トレーニングとスコアリングのスケジュール** | モデルのトレーニングとスコアリングは、[&#x200B; モデルを構築](/help/models/build.md#schedule)する場合と、[&#x200B; モデルinsight](/help/models/insights.md#edit)またはモデルの[&#x200B; コンテキストメニュー](/help/models/overview.md#edit)からモデルを編集する場合に、モデルのテーブルでスケジュールできます。 | 2024年10月21日（PT） |
| **タッチポイント分類テーブル** | [!UICONTROL Models]では、[[!UICONTROL Model insights]](/help/models/insights.md#factors) タブに追加の[&#x200B; タッチポイント分類](../models/insights.md#touchpoint-breakdown) テーブルが表示されるようになりました。 | 2024年10月1日（PT） |

## 2024年8月

| 機能 | 説明 | 一般公開（GA） |
|---|---|---|
| **貢献度インサイト** | [!UICONTROL Models]では、[[!UICONTROL Factors]](/help/models/insights.md#factors) タブに外部要因に関連するインサイトが表示されます。 | 2024年8月20日（PT） |
| **限界応答カーブ** | モデルインサイトの[限界応答曲線](/help/models/insights.md#model-insights-1)のビジュアライゼーションで、選択したデータ範囲の変更に基づいて曲線と対応する値が更新されるようになりました。 さらに、このビジュアライゼーションには、限界損益分岐点と収穫逓減ポイントが表示されます。 | 2024年8月20日（PT） |
| **高度なトレーニングとスコアリング** | モデル [retrain](/help/models/overview.md#retrain)、[&#x200B; スコア（新しいマーケティングデータの場合）またはrescore](/help/models/overview.md#score-or-rescore)をモデル インターフェイスから開始できます。 | 2024年8月13日（PT） |
| **ポリシーの適用** | Experience Platform ポリシーは、データセットルールを設定する場合や、Mix Modelerで使用される基になるデータにラベルを変更する場合に適用されます。 詳しくは、[&#x200B; ポリシー](../data-governance/policies.md)を参照してください。 | 2024年8月13日（PT） |
| **データハイジーン** | データハイジーンルールは、ソースデータを削除する際に尊重されます。 [&#x200B; ソースデータセットの削除](../harmonize-data/dataset-rules.md#delete-a-source-dataset)を参照してください | 2024年8月13日（PT） |

## 2024年6月

| 機能 | 説明 | 一般公開（GA） |
|---|---|---|
| **MTA ビジュアライゼーション** | モデルインサイトは、包括的な[MTA ビジュアライゼーション &#x200B;](../models/insights.md#attribution)で更新されます。 | 2024年6月18日（PT） |
| **CPA指標** | CPA （アクション単価）指標は、[&#x200B; プランの比較](../plans/compare.md)で利用できます。 | 2024年6月18日（PT） |
| **フィールドレベルのアクセス制御** | データセットルールを定義する場合、Experience Platformの[属性ベースのアクセス制御](https://experienceleague.adobe.com/en/docs/experience-platform/access-control/abac/overview)が[&#x200B; フィールドレベル &#x200B;](../harmonize-data/dataset-rules.md#field-level-access-control)に適用されます。 | 2024年6月12日（PT） |
| **以前のナレッジタッチポイント** | [!UICONTROL Configure] ステップで指定されたマーケティング タッチポイントのみが、[[!UICONTROL Prior Knowledge]](../models/build.md) セクションで選択できます。 | 2024年6月12日（PT） |

## 2024年5月

| 機能 | 説明 | 一般公開（GA） |
|---|---|---|
| **データ結合の環境設定** [!BADGE &#x200B; ベータ &#x200B;] | [&#x200B; データ結合の環境設定](../harmonize-data/dataset-rules.md#data-merge-preferences)は、要約およびイベントデータソースのデータを結合する際の競合の解決に役立ちます。 | 2024年5月29日（PT） |

{style="table-layout:auto"}




## 2024年4月

| 機能 | 説明 | 一般公開（GA） |
|---|---|---|
| **日付の再表示オプション** | 集計データセットの場合、[&#x200B; ルール &#x200B;](../harmonize-data/dataset-rules.md)を定義する際に、データの再表示が集計または置換のどちらを使用するかを定義できます。 | 2024年4月1日（PT） |
| **モデル品質の更新** | モデル インサイトの[&#x200B; モデル品質](/help/models/insights.md)に、モデル評価のビジュアライゼーションと、モデル適合指標を含むテーブルが表示されるようになりました。 | 2024年4月1日（PT） |


## 2024年1月

| 機能 | 説明 | 一般公開（GA） |
|---|---|---|
| **強化されたダウンロード** | Microsoft® Excel形式で[完全なモデルインサイト &#x200B;](../models/insights.md)をダウンロードできます | 2024年1月31日 |
| **限界応答カーブ** | [&#x200B; モデルインサイト &#x200B;](../models/insights.md)は、限界応答曲線を表示するための追加のビジュアライゼーションを提供します。 | 2024年1月31日 |
| **データ結合の環境設定** | 調整されたデータセットのデータセットルールに対して[&#x200B; データ結合の環境設定](../harmonize-data/dataset-rules.md#data-merge-preferences)を定義できます。 | 2024年1月31日 |
| **使用状況レポート** | Harmonized datasets UIには、モデルとコンバージョンの使用状況に関する追加のインサイトを提供する追加の[使用状況レポート &#x200B;](../harmonize-data/usage-report.md) タブがあります。 | 2024年1月31日 |
| **更新されたプラン インサイト UI** | プランインサイト UIが更新され、レポートするROIとチャネルを選択できるようになります。 | 2024年1月31日 |
