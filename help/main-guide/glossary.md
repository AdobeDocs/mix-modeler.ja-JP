# Mix Modeler用語

ドキュメントでは、次の用語と頭字語を使用しています。

| 用語または略語 | 定義 |
|---|---|
| **Experience Platform （AEP）** | Experience Platformは、企業全体のデータとコンテンツを標準化し、リアルタイムの消費者プロファイルを強化します。これにより、データサイエンスを可能にし、コンテンツベロシティを加速させることで、カスタマージャーニー全体でエクスペリエンスのパーソナライゼーションを促進できます。 |
| **集計または概要データ** | グループごとの詳細なデータ（例：消費者、キャンペーン、地域） 自社と接触し、あるいは自社のビジネスで活動する |
| **コンバージョン** | ユーザーが実行するアクションはすべて、ビジネスにとって価値のあるものと見なされます。 新規登録や製品の購入など。 |
| **イベントデータ** | イベントタイムスタンプと人物IDを含む、イベントレベルのマーケティングタッチポイントデータまたはコンバージョンデータ |
| **インスタンス** | 目的と設定の独自のセットを持つデータサイエンスパイプラインの1つのコピー。 |
| **マーケティングタッチポイント** | 見込み客/リードがオンラインまたはオフラインのマーケティング施策で得たインタラクション。 |
| **マーケティングアトリビューション** | マーケティングのタッチポイントに収益クレジットを割り当てるプロセス。 これは、見込み客との最初のインタラクションから商談が成立するタイミングに至るまで、カスタマージャーニー全体を追跡することで達成されます。 取引から生じた売上は、売上につながったマーケティング接点に起因します。 各顧客接点に対する貢献度は、各顧客接点が顧客の購入に与えた影響の大きさによって異なります。 |
| **マルチタッチアトリビューション （MTA）** | カスタマージャーニーにおける最も効果的なマーケティング接点を特定し、貢献度を明らかにするマーケティング戦略。 |
| **マーケティングミックスモデリング（MMM）** | マシンラーニングモデルを適用して、マーケティングへの投資が主要なビジネス目標に与えた効果を過去および将来にわたって明らかにすることで、マーケティングへの投資を測定、最適化、計画できるサービス。 |
| **予測リターン** | 予測収益 – 支出 |
| **予測ROI** | 予測収益/支出<br>または<br> （予測収益 – 支出） / 支出 |
| **予測ROI （%）** | （（売上予測 – 支出） / 支出） x 100% |
| **チャネルのCPAを予測** | チャネル支出/すべての有料チャネルに起因する予測コンバージョン数 |
| **全体的な有料チャネルの予測CPA** | 有料チャネルの総支出額/すべての有料チャネルに起因するコンバージョンの予測数 |
| **破棄されたCPAの合計** | 総支出額/予測コンバージョン数（全チャネルおよび基本チャネル） |
